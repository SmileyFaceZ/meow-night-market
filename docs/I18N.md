# ภาษา (i18n)

- ภาษาเริ่มต้น: ไทย (`th`) · รอง: อังกฤษ (`en`) · จำค่าที่เลือกไว้ใน localStorage · ตรวจภาษาเบราว์เซอร์ครั้งแรก
- ใช้ `react-i18next` (หรือ context เล็กๆ ถ้าต้องการเบา) คีย์แบบจุด เช่น `phase.bidding.title`
- ห้ามต่อสตริงเอง ให้ใช้ตัวแปรในข้อความ เช่น `"{{name}} กินปลามื้อใหญ่! +{{points}}"`
- ตัวเลข: เลขอารบิก (ไม่ใช้เลขไทย) · ใช้ `Intl.PluralRules` สำหรับอังกฤษ
- เพิ่ม test ตรวจว่า `th.json` และ `en.json` มีคีย์ตรงกันทุกคีย์

## น้ำเสียง
ภาษาไทยเป็นกันเอง สนุก สั้น ใช้ "เรา/เธอ" หรือไม่ระบุสรรพนาม หลีกเลี่ยงภาษาทางการ
ใส่คำเลียนเสียงได้พอประมาณ (เหมียว~ โฮ่ง! งั่มๆ) ข้อความปุ่มสั้นไม่เกิน ~10 ตัวอักษรไทยถ้าทำได้
