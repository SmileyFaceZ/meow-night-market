# Art Direction & UX — แมวตลาดโต้รุ่ง

## บรรยากาศ
ตลาดโต้รุ่งไทยตอนกลางคืนแบบอบอุ่นน่ารัก: ไฟหลอดกลมห้อยเป็นสาย ผ้าใบแผงลอยลายทาง
ป้ายราคากระดาษเขียนมือ กลิ่นอายสติกเกอร์ไลน์ ไม่น่ากลัว แม้แต่หมายามก็ดูตลกมากกว่าดุ

## สไตล์ภาพ
- Flat vector น่ารัก เส้นขอบหนา (2.5–3px) สีเข้มอมม่วง `#3B2A4A` มุมโค้งมน สัดส่วนหัวโต (chibi)
- ตัวละครและอาหารมีหน้าตา (ตาจุด แก้มชมพู) เช่น ปลายิ้ม กล่องนมขยิบตา
- **วาดทุกอย่างเป็น SVG React component** ใน `src/art/` ใช้สีจาก CSS variables เพื่อรองรับธีม
- ห้ามใช้รูปจากอินเทอร์เน็ต ห้ามคล้ายตัวละครที่มีลิขสิทธิ์

## การ์ด
- อัตราส่วน 5:7 มุมโค้ง 14px เงานุ่ม ขนาดยืดตามจอ (มือถือ ~72px กว้าง ในมือ, ~110px บนแผง)
- องค์ประกอบ: ภาพกลางใหญ่ · ชื่อไทยด้านล่าง · ไอคอนเล็กมุมซ้ายบน (อ่านได้ตอนการ์ดซ้อนกัน)
- หลังการ์ดแผงตลาด: ลายผ้าใบแดงขาว · หลังการ์ดถังขยะ: ถังสังกะสีมีหางแมวโผล่
- การ์ดเสียงเหมียว: ฟองคำพูดรูปหัวแมว ตัวเลขใหญ่ จำนวน "เหมียว~" ตามเลข
- ป้ายราคาตลาด: ป้ายกระดาษแขวนเหนือแผง ตัวเลขใหญ่ ขีดฆ่าราคาเก่าเวลาลด

## ตัวละครผู้เล่น
แมว 8 ตัว: ส้ม ดำ ขาว สามสี สีสวาด (เทาเงิน ตาเขียว) วิเชียรมาศ (หน้ากาก/หูเข้ม) ลายสลิด (ลายทาง) ตุ้ยนุ้ย (หน้ากว้าง ปากขาว)
— มีสีหน้า 4 แบบ (ปกติ ดีใจ ตกใจ อิ่ม) เปลี่ยนตามเหตุการณ์ · ในเกมเดียวกันแมวห้ามซ้ำ
ผู้เล่นมนุษย์เลือกแมวและตั้งชื่อเล่นได้ (ไม่เกิน 12 ตัวอักษร)

## ตลาดป่วน (v2 — `art/PowerIcon.tsx`, `art/EventIcon.tsx`, `components/Mayhem.tsx`)
- **ไอคอนพลัง 8 แบบ** = วงกลมสี + สัญลักษณ์หนาเส้นหมึก อ่านออกที่ 24px: จมูกไว = จมูกชมพูมีเส้นดม · เปลี่ยนใจ = ลูกศรวนสองอัน ·
  เก็บของเก่ง = รอยเท้าแมว · โชคดี = ใบโคลเวอร์ 4 แฉก · แมวนำโชค = กระดิ่งแมว · สั่งพิเศษ = การ์ด 2 ใบ + บวก ·
  ต่อราคา = ป้ายราคา + ลูกศรขึ้น · กินจุ = ชามพูน
  · ติดมุมซ้ายบนของรูปแมวบนป้ายผู้เล่น (ใช้แล้ว = เทาจาง) · แตะป้ายผู้เล่นดูชื่อพลัง + คำอธิบาย 1 บรรทัด ·
  ตอนเลือกแมว (เมื่อเปิดพลัง) แสดงพลังของแมวที่เลือกใต้ตาราง
- **ปุ่มใช้พลัง** เรืองแสงเป็นจังหวะ (ขอบโคม) ขึ้นเฉพาะตอนที่ใช้ได้จริง ในจุดที่เกี่ยวข้อง: จมูกไว ใต้ปุ่มคุ้ย · แมวนำโชค
  ใต้ปุ่มโยนกระดูก · สั่งพิเศษ ในตาเลือกของ · เก็บของเก่ง/ต่อราคา เปิดหน้าต่างเลือก · กินจุ เป็นปุ่มมื้อ 2 ใบ
  · พลังที่เกมหยุดรอ (โชคดี/เปลี่ยนใจ): แถบคำแนะนำบอกเจ้าของว่าทำอะไรได้ + ปุ่ม "ไม่ใช้" · คนอื่นเห็น "(ชื่อ) กำลังคิดเรื่องพลัง…"
  · จมูกไว: แถบ "ใบถัดไปในถัง" เห็นคนเดียว อัปเดตทุกครั้งที่จั่ว
- **ตอนใช้พลัง** ทุกคนเห็นจังหวะใหญ่: แมว + ไอคอนเด้ง + ประกายดาว + ชื่อพลังตัวโต · เปลี่ยนใจ = ใบเหมียวเดิม → ใบใหม่ ·
  โชคดี = การ์ดเดิมร่วง ใบใหม่ลงแทน
- **การ์ดเหตุการณ์ 13 ใบ** = กระเบื้องสี่เหลี่ยมมุมมน สีตามอารมณ์ (ฟ้า = อากาศ, อุ่น = โชค, ม่วง = ลูกเล่น) ·
  ต้นรอบเปิดใหญ่กลางจอ (พลิก + ชื่อ + ผล 1 บรรทัด, 2.2 วินาที) ก่อนประกาศรอบ · มุมขวาของแถวลำดับตัดสินเสมอมีชิปเหตุการณ์ของรอบ
  แตะดูรายละเอียด + เหตุการณ์รอบก่อนๆ + จำนวนที่เหลือ
- **ฉาก** (อยู่หลังกระดาน ไม่รับการแตะ): ฝนตกหนัก = เม็ดฝนตก + โทนฟ้าเข้ม · ไฟดับ = ขอบจอมืด · พระจันทร์เต็มดวง = จันทร์จางๆ มุมขวาบน
  · reduced motion = ภาพนิ่ง (เม็ดฝนหยุด)
- ไฟดับ: การ์ดคว่ำบนแผงใช้หลังการ์ดแผง แตะเลือกได้ (ไม่รู้ว่าเป็นอะไร) · ถังขยะแสดงป้ายเสริม: จั่วแล้ว x/4 (รถขยะ) ·
  หมาหลบฝน n ตัว · หมาตัวแรกจะหลับอยู่ · ลมแรง: แตะการ์ดในมือ 1 ใบ แล้วกด "ส่งใบนี้" → เปิดพร้อมกันเป็นแถว แมว → การ์ด → แมว
- **คำอธิบาย 2 หน้า** (`components/MayhemIntro.tsx`): หน้า 1 พลังแมว = แมว 8 ตัวติดไอคอนพลัง · หน้า 2 เหตุการณ์ = ตัวอย่าง 4 ใบ
  · ขึ้นครั้งแรกที่สวิตช์โหมดมีตลาดป่วนเปิดอยู่ (DECISIONS 049) · ปุ่ม "ตลาดป่วนคืออะไร?" เปิดซ้ำได้
- **หน้าวิธีเล่น** มี 2 แท็บ: พื้นฐาน · ตลาดป่วน (กติการ่วม + แมว 8 ตัวกับพลัง + เหตุการณ์ครบ 13 ใบ)

## เลย์เอาต์
- **มือถือแนวตั้ง (หลัก):** บนสุด = คู่แข่ง (อวตาร์ แต้ม จำนวนการ์ด) · กลาง = แผง ราคาตลาด กองถังขยะ · ล่าง = มือของเรา + ปุ่มแอคชัน
- **เดสก์ท็อป:** โต๊ะกลาง คู่แข่งรอบโต๊ะ แถบประวัติด้านข้าง
- แสดงเสมอว่าตอนนี้ช่วงอะไร ตาใคร และต้องทำอะไร (แถบข้อความใหญ่ 1 บรรทัด)
- ปุ่มที่กดได้เรืองแสงเบาๆ ปุ่มที่กดไม่ได้จางลงพร้อมเหตุผลเมื่อแตะ

## แอนิเมชัน (Framer Motion)
- แจกการ์ด: ลอยจากกองไปตำแหน่ง ทีละใบ 80ms
- เปิดเสียงเหมียวพร้อมกัน: พลิกการ์ดพร้อมกัน + ฟองคำพูด "เหมียว!" · ชนกัน = การ์ดสั่นและมีฝุ่นตีกัน
- คุ้ยถังขยะ: ถังสั่นก่อนเปิด (ลุ้น) · หมายาม = หน้าจอสั่นเบาๆ + หมาเห่า "โฮ่ง!" + การ์ดในถุงปลิวออก
- กินอาหาร: การ์ดลอยเข้าปากแมว แมวเปลี่ยนเป็นหน้าอิ่ม + ตัวเลขแต้มเด้งขึ้น · ป้ายราคาหมุนแล้วลด
- จบเกม: แมวผู้ชนะใส่มงกุฎ กระดาษสีโปรย
- ทุกแอนิเมชันต้องข้ามได้ (แตะเพื่อเร่ง) และปิดเมื่อ `prefers-reduced-motion`
- **จังหวะ (ของจริงในโค้ด `game/stage.ts`):** เหตุการณ์เล่นทีละอัน มีเวลาอ่าน 0.65–1.7 วินาที เกมรอจนแสดงครบ
  เหตุการณ์ใหญ่บังกระดาน (แตะ/Enter/Esc = ข้าม) ส่วนหยิบ/คุ้ย/เก็บถุงเป็นป้ายเล็ก · reduced motion = ไม่เคลื่อนไหวแต่เวลาอ่านเท่าเดิม
- **ถังขยะ 4 อารมณ์** แทนตัวเลขความเสี่ยง: เงียบ (< 15%) · ได้ยินเสียงแปลกๆ (15–25%) · หมาอยู่แถวนี้ (> 25%) · เหลือแต่หมา — แตะดูตัวเลข
- **สีหน้าแมวบนกระดาน:** อิ่มหลังกิน / ดีใจหลังได้ของ ค้างไว้ทั้งรอบ · ตกใจตอนหมาเห่าหรือชนกัน · เริ่มรอบใหม่กลับหน้าปกติ
- **ป้าเหมียว** (แมวสามสี) เป็นผู้สอนในบทสอน
- **หน้าบังจอ "ส่งเครื่องให้…"** (เล่นเครื่องเดียว): พื้นทึบ (ไม่เห็นกระดานข้างหลัง) แมวของคนถัดไป + ชื่อ + ต้องทำอะไร
  ช่วงลับ (ลงเลข/ทิ้งการ์ด) มีป้าย "ห้ามแอบดู" · ปุ่ม "ฉันคือ…" กดได้หลัง 0.7 วินาที กันแตะซ้ำจากคนก่อน
  · บนจอที่ใช้ร่วมกันเรียกทุกคนด้วยชื่อ ไม่ใช้คำว่า "เธอ" ในประวัติ/เหตุการณ์/ผลเกม
- **สติกเกอร์แมว** (ออนไลน์): 8 แบบ = หน้าแมวสีของผู้ส่ง (อารมณ์ตามสติกเกอร์) + คำสั้น เช่น เหมียว~ งั่มๆ เก่งมาก!
  ลอยขึ้นใต้แถบบน 3 วินาที · ไม่มีแชทพิมพ์อิสระ
- **ออนไลน์:** ตัวจับเวลาใต้แถบคำแนะนำ (แดงเมื่อเหลือ ≤ 10 วิ) · คนที่หลุด: แมวซีดเทา + "หลุดไป…" / "บอทเล่นแทน"
  · ห้องรอเล่น: รหัสห้องตัวใหญ่ (อ่านออกเสียงให้เพื่อนได้) ปุ่มคัดลอกลิงก์ + ชวนเพื่อน (Web Share) มงกุฎ = เจ้าของห้อง
- **ไอคอนเว็บ** `apps/web/public/favicon.svg` หน้าแมวสามสี (ทำไว้ก่อนเพื่อไม่ให้มี 404 ใน console — เฟส 7 ทำเพิ่มสำหรับ PWA)

## เสียง
เสียงสั้นน่ารัก **สังเคราะห์ด้วย Web Audio ทั้งหมด** (`apps/web/src/audio/sound.ts`) — ไม่มีไฟล์เสียง ไม่มีเรื่องลิขสิทธิ์
- **เสียงกดปุ่ม:** ปุ่ม/ลิงก์/สวิตช์ทุกอันดัง "ต๊อก" เบาๆ (listener เดียวทั้งแอป) · การ์ดอาหาร = เสียงพลิกการ์ด ·
  ใบเหมียว = "เมี้ยว" สูงต่ำตามเลข 1–5 · ปุ่มที่กดไม่ได้ = "อึ๊บ อึ๊บ" ต่ำๆ · ตั้งเสียงเฉพาะได้ด้วย `data-sound` (`none` = เงียบ)
- **เสียงในเกม** ดังตอนจังหวะเหตุการณ์นั้นขึ้นจอ (ตรงกับแอนิเมชัน): รอบใหม่ = ระฆังโคม 2 เสียง · เปิดเลข = กลอง + ติ๊ง ·
  ชนกัน = "โบ๋ง" เพี้ยนๆ · คุ้ยถัง = กรอบแกรบ · หมา = โฮ่ง โฮ่ง · โดนหมา = "วา-วา" เศร้า · โยนกระดูก = วืด + ป๊อก ·
  เก็บลงถุง = ป๊อป · กิน = งั่ม งั่ม + กริ๊งขึ้น · ข้ามตา = ปิ๊วลง · ทิ้งการ์ด = ฟึ่บ · จบเกม = แตรสั้น ·
  ถึงตาเธอ = ติ๊ง-ต่อง · 5 วินาทีสุดท้าย (ออนไลน์) = ติ๊กทุกวินาที · สติกเกอร์มาถึง = ป๊อป
  · ตาของตัวเองที่เพิ่งกด (หยิบของ) ไม่ดังซ้ำ
  · ตลาดป่วน: ใช้พลัง/พลังคืน = ประกายระฆังไล่ขึ้น 3 เสียง · เปิดการ์ดเหตุการณ์ = กลองรัวสั้น + ระฆัง 2 เสียง ·
  เปลี่ยนใจ/โชคดี = เสียงพลิกการ์ด · ได้ของฟรี/เก็บจากกองทิ้ง = ป๊อป · ราคาเปลี่ยน = ป๊อปเบา · หมาหลับ = ปิ๊วลง · ลมพัดการ์ด = ฟึ่บ
- **ตั้งค่าเสียง** (ปุ่มลำโพงหน้าแรก + ในเมนู ☰ ระหว่างเกม): เปิด/ปิดเสียงทั้งหมด · ความดัง (ค่าเริ่มต้น 40% — เบา) ·
  เสียงกดปุ่ม · เสียงในเกม — บันทึกในเครื่อง (`mnm.sound.v1`) · ไอคอนลำโพงมีขีดฆ่าเมื่อปิด
